# Helping Us Help Her: concept site

A design concept for [Helping Us Help Her](https://huhh.org), Grand Prairie, Texas, prepared by Taylormade Creative.
Three pages: the front page, an impact report and the Golf Classic campaign page.

Facts and quotes come from huhh.org. Some photographs are creative-direction frames rather than HUHH event photography, and are labeled as such in the footer.
